Research

Three questions I keep coming back to

My work sits between data visualization, human perception, and AI. Each thread links to the papers behind it.

  1. 01

    Can people read this chart?

    Measuring visualization literacy quickly and reliably. Mini-VLAT, a 12-item test, won Best Paper at EuroVis 2023, and I've since used these tests to benchmark vision-language models.

  2. 02

    Do they trust what they see?

    What makes a visualization feel trustworthy, which factors build or erode that trust, and how to measure it as more than a single number, from the viewer's side of the chart.

  3. 03

    What happens when AI reads, and makes, images?

    Vision-language models on literacy tests, multi-agent LLM systems that help people design charts, and when detectors can (and can't) tell a generated image from a real one.

Open source

Two fixes in CPython

CPython is the main implementation of Python, the one most people install. In November 2026, two of my patches were merged into it.

Merged Lib/datetime·Nov 6, 2026

date.fromisoformat() stopped ignoring trailing characters

>>> date.fromisoformat('2020010112')
# before datetime.date(2020, 1, 1)
# after ValueError: Invalid isoformat string

I came across this while working with Python's datetime module: a ten-character string like '2020010112' quietly turned into January 1, 2020, with the last two characters thrown away. I sent in a fix for both the C and pure-Python parsers, along with tests. It took a couple of weeks of patience (lol), but it was approved and merged, then backported to Python 3.15 and 3.14. I did the 3.14 backport by hand after the automatic one hit a conflict.

Pull request #160737 3.14 backport

Merged Modules/_ctypes·Nov 4, 2026

Resized ctypes objects no longer read or write out of bounds

>>> ctypes.resize(obj, 64) # grow past its type
# before bool(obj) read past a 16-byte buffer
# after bool(obj) reads only sizeof(type)

After ctypes.resize(), a simple object's buffer is larger than its type. bool() and passing the object to a C function still used the buffer's size, so bool() read past the end of an internal 16-byte buffer, and the call copied the whole buffer into a fixed-size slot, corrupting the heap. The fix uses the type's size instead, matching how the value getter already worked.

Pull request #160720 Commit 44579b0

WSPA 7News · November 2026

AI agent at your service: Is this new tech right for you?

WSPA 7News interviewed me about AI agents built for everyday consumers. My advice: limit how much independence you give them, take the companies' own warnings that they make mistakes seriously, and watch out for prompt injection, where hidden instructions hijack an agent into doing things you never asked for.
